# ربات فروش دوره‌ها (تلگرام)

ربات کامل فروش دوره با aiogram 3 و SQLite. محصولات را ادمین داخل خود ربات وارد می‌کند.
پرداخت با **زرین‌پال** یا **کارت‌به‌کارت با تایید ادمین**؛ تحویل با **لینک یک‌بارمصرف کانال/گروه خصوصی**،
**کد لایسنس** یا **متن/لینک ثابت**.

## قابلیت‌ها
**مشتری**
- کاتالوگ، صفحه‌ی دوره، لینک مستقیم `t.me/<bot>?start=p_<id>` و ردیابی منبع ورود با `?start=<هر_متن>`
- خرید آنلاین (زرین‌پال) یا کارت‌به‌کارت با ارسال عکس رسید
- **کد تخفیف** (درصدی/مبلغ ثابت، محدود به تعداد، انقضا، دوره یا کاربر خاص؛ ۱۰۰٪ = سفارش رایگان)
- **دعوت دوستان:** لینک اختصاصی `?start=ref_<id>`؛ با اولین خرید دوست، یک کد تخفیف یک‌بارمصرف برای معرف ساخته می‌شود
- **یادآوری سفارش رهاشده** (بعد از ۲ ساعت، فقط یک‌بار، فقط اگر همان دوره را نخریده باشد)
- «دوره‌های من» با ارسال دوباره‌ی دسترسی
- **پشتیبانی داخل ربات:** پیام کاربر برای ادمین‌ها می‌رود و ادمین با Reply جواب می‌دهد

**ادمین (`/admin`)**
- محصولات: افزودن، ویرایش (عنوان/توضیح/قیمت/کانال/متن دسترسی)، فعال/غیرفعال، حذف، افزودن کد لایسنس
- رسیدها: تایید/رد با یک دکمه؛ سفارش‌های اخیر، جزئیات (`/order 123`)، ارسال دوباره‌ی دسترسی، **استرداد** (قطع دسترسی و حذف از کانال)
- کدهای تخفیف: ساخت/حذف
- آمار: کاربر، سفارش، نرخ تبدیل، درآمد کل و ۷ روز اخیر، **گزارش به تفکیک منبع ورود**
- پیام همگانی، **خروجی CSV** سفارش‌ها
- `/set force_channel @کانال` — **قفل عضویت**؛ `/set referral_percent 10` — درصد پاداش معرفی

**زیرساخت**
- ضداسپم (فاصله‌ی حداقلی بین رویدادها)، مهاجرت نسخه‌دار دیتابیس، تحویل اتمیک و فقط یک‌بار
- Docker، systemd، Caddy، اسکریپت پشتیبان‌گیری، CI گیت‌هاب

## راه‌اندازی
```bash
pip install -r requirements.txt
cp .env.example .env   # مقادیر را پر کنید
set -a; source .env; set +a
python -m bot.main
```
با Docker: `docker compose up -d --build`. نمونه‌ی فایل سرویس و Caddy در `deploy/` است.

### تنظیمات `.env`
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | از @BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها با کاما |
| `CARD_NUMBER` / `CARD_HOLDER` | فعال‌سازی کارت‌به‌کارت |
| `ZARINPAL_MERCHANT_ID` + `PUBLIC_BASE_URL` | پرداخت آنلاین. آدرس باید HTTPS و عمومی باشد؛ مسیر بازگشت `/pay/callback` |
| `ZARINPAL_SANDBOX` | `true` برای تست |
| `SUPPORT_USERNAME` | یوزرنیم پشتیبانی (اختیاری؛ پیام‌رسانی داخل ربات بدون آن هم کار می‌کند) |

### تحویل با لینک کانال
ربات را **ادمین** کانال/گروه خصوصی دوره کنید (با دسترسی دعوت کاربر و برای استرداد، مسدود کردن کاربر). آیدی عددی کانال (`-100…`) را هنگام ساخت محصول بدهید.
برای قفل عضویت هم ربات باید در کانال ادمین باشد؛ در غیر این صورت قفل برای جلوگیری از توقف فروش نادیده گرفته می‌شود.

## نکات عملیاتی
- مبلغ‌ها **تومان** ذخیره می‌شوند؛ حداقل پرداخت آنلاین ۱٬۰۰۰ تومان است.
- ظرفیت کد تخفیف هنگام ساخت سفارش رزرو می‌شود؛ با رد رسید برمی‌گردد. سفارشِ بدون پرداخت، ظرفیت را نگه می‌دارد.
- استرداد فقط وضعیت و دسترسی را عوض می‌کند؛ پول را خودتان برگردانید.
- پیام همگانی فعلاً با parse mode پیش‌فرض ربات (HTML) ارسال می‌شود؛ `<` و `&` را رعایت کنید.
- حالت چندسرور/چندنمونه پشتیبانی نمی‌شود (SQLite و FSM در حافظه). برای پشتیبان‌گیری: `deploy/backup.sh`.

## حالت سرورلس
