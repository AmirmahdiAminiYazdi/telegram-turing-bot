# ربات فروش دوره‌ها (تلگرام)

ربات فروش دوره با aiogram 3. محصولات را ادمین داخل خود ربات وارد می‌کند.
پرداخت با **زرین‌پال** یا **کارت‌به‌کارت با تایید ادمین** است. تحویل دوره از دو راه انجام می‌شود:
**لینک یک‌بارمصرف کانال/گروه خصوصی** و **کد/لینک دسترسی** (ثابت یا از یک استخر کد لایسنس).

## قابلیت‌ها (نسخه ۱)
- کاتالوگ دوره‌ها، صفحه محصول و لینک مستقیم `t.me/<bot>?start=p_<id>`
- ردیابی منبع ورود کاربر با `?start=<هر_متن>` (در جدول `users.source` ذخیره می‌شود)
- پرداخت آنلاین (زرین‌پال) با تایید خودکار و تحویل فقط یک‌بار (حتی با رفرش صفحه)
- کارت‌به‌کارت: کاربر عکس رسید می‌فرستد، ادمین با یک دکمه تایید یا رد می‌کند
- «دوره‌های من» و ارسال دوباره دسترسی
- پنل ادمین (`/admin`): افزودن/فعال‌سازی/حذف محصول، افزودن کد لایسنس، رسیدهای منتظر، آمار و پیام همگانی

## راه‌اندازی
```bash
pip install -r requirements.txt
cp .env.example .env   # مقادیر را پر کنید
set -a; source .env; set +a
python -m bot.main
```

### تنظیمات مهم
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | از @BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها با کاما |
| `CARD_NUMBER` / `CARD_HOLDER` | فعال‌سازی کارت‌به‌کارت |
| `ZARINPAL_MERCHANT_ID` + `PUBLIC_BASE_URL` | فعال‌سازی پرداخت آنلاین. آدرس باید HTTPS و از اینترنت در دسترس باشد؛ مسیر بازگشت `/pay/callback` است |
| `ZARINPAL_SANDBOX` | `true` برای تست |

### تحویل با لینک کانال
ربات را **ادمین** کانال/گروه خصوصی دوره کنید (با دسترسی دعوت کاربر). آیدی عددی کانال (مثل `-100…`) را هنگام ساخت محصول وارد کنید.

## حالت سرورلس
نسخه‌ی بدون سرور روی Telegram Serverless در پوشه‌ی [`serverless/`](serverless/README.md) است.

## تست
```bash
pip install -r requirements-dev.txt
pytest
```

## ساختار
```
bot/main.py          نقطه ورود (polling + سرور بازگشت درگاه)
bot/handlers/        user.py و admin.py
bot/services/        zarinpal.py و delivery.py
bot/web.py           مسیر /pay/callback
bot/db.py            SQLite (aiosqlite)
```
